# Support

## Getting Help

- Usage questions: open a GitHub Discussion or issue
- Bug reports: use the Bug Report issue template
- Security concerns: see SECURITY.md

## Before Opening an Issue

1. Read README.md and CONTRIBUTING.md
2. Re-run with the latest `main`
3. Include command output and repro steps

## Maintainer Scope

Maintainers prioritize:
- Reproducible bugs
- Documentation fixes
- Contributions aligned with the project roadmap
