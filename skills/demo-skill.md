# Demo Skill

## Instructions
- Always write clean code
- Use TypeScript for new projects
- Follow ESLint rules

## Guidelines
- Before writing any function, add comments explaining the purpose
- Include JSDoc for all public APIs
- Write unit tests for every function

## Examples
```typescript
function add(a: number, b: number): number {
  return a + b;
}
```

## Code Style
- Use 2 spaces for indentation
- Use single quotes
- Add trailing commas
